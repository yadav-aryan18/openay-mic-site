Before you download

QUICK ANSWERS
  • Is it really free? Yes — MIT. The files are hosted by GitHub Releases; this page only points at them. Nothing here is metered or gated.
  • Does my phone need root? No. Everything runs in user space on both the phone and the desktop.
  • Will Windows see it as a microphone? On Linux the receiver creates a PipeWire source — a system-wide mic every app can pick. On Windows it renders through WASAPI; pair it with a virtual-audio-cable driver (VB-Cable and friends) to expose it as a mic, the same way OBS does.
  • Wi-Fi, USB or Bluetooth? Same Wi-Fi network for UDP, or a USB cable for TCP-over-adb (zero packet loss — the Windows build bundles adb). Bluetooth SPP is implemented and coming to a release soon.
  • How current are these files? The list is baked from GitHub when the site deploys; the repo's releases page is always the source of truth. v0.1.0 ships a SHA256SUMS.txt — verify before you trust any binary.
